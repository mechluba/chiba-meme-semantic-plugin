# 千叶热梗发现与审核规则

## 1. 审核对象的两个维度

内容类型和千叶的使用策略必须分开审核，不能再把“不是梗”和“不可主动使用”混成同一个淘汰结果。

### 1.1 内容类型

- `meme`（梗）：字面意义与真实表达意图不一致，通常依赖事件、名场面、圈层共识、中文或中日谐音、同义替换，或特殊句式模板才能正确理解。
- `catchphrase`（口癖/口头禅）：字面意义通常没有明显反转，但在高频交流中承担稳定的态度或互动功能，例如惊讶、认可、催促、收尾、调侃。它可以进入语义库，但不应伪装成有特定典故的梗。
- `ordinary`（普通表达）：只有字面含义，且没有值得单独学习的稳定交流功能。
- `noise`（噪音）：系统文案、时间提示、活动广告、用户名残片、表情占位符等，不进入审核池。

### 1.2 千叶使用策略

- `refine`（可学习使用）：千叶既要理解，也可以在意图、关系、场景和时效均匹配时主动使用。
- `understand`（仅理解）：千叶要能还原用户真实意图，但默认不主动复读。高冒犯性、强圈层身份、容易尴尬、已明显过时或来源不明的表达优先放在这里。
- `skip`（忽略）：没有单独建卡价值。

口癖不等于“可使用”，梗也不等于“仅理解”。二者需要分别判断。

## 2. 规范条目与变体合并

同一个表达单位只保留一个规范条目，其他写法放入 `aliases`，并记录关系类型：

- `orthographic_variant`：标点、空格、大小写差异；
- `homophone_variant`：中文谐音；
- `bilingual_homophone_variant`：中英或中日混合谐音；
- `synonym_variant`：同义词或省略句变体；
- `template_variant`：同一句式模板中的槽位替换；
- `meme_family`：共享核心语义但仍可能需要不同使用条件的表达族。

模板族不能只因为词面相近就强行合并。若成员的交流意图、冒犯等级或适用场景不同，应保留为同族的独立语义原型。

## 3. 进入审核池前的清洗

原始弹幕和评论归档保持不变，黑名单只作用于“候选挖掘输入”，并输出按原因统计的清洗报告。当前先排除：

- 明确的系统/活动文案；
- `@用户`、相对时间、进度提示等页面结构噪音；
- 纯表情占位符；
- 已确认无语义价值的精确黑名单词；
- 配置中命中的包含词和正则表达式。

黑名单需要可追溯，不能静默删除原始证据；误杀时可以从归档重新构建候选池。

## 5. 生命周期与复审

### 5.1 库存梗降权

程序根据最后观测时间计算指数衰减，只生成待审队列，不直接修改运行时梗库。默认半衰期：

- 突发梗 `breaking`：14 天；
- 当期热梗 `current_observed`：45 天；
- 季节性表达 `seasonal`：120 天；
- 常青表达 `evergreen`：365 天。

年龄不足 21 天不进入降权审核；建议权重低于 0.45 时进入人工队列，由人选择 `KEEP`、`DOWNRANK` 或 `RETIRE`。

### 5.2 淘汰项重新评审

淘汰项达到 30 天冷却期后，按审核日期生成稳定随机候选，每批默认 20 条。同一条在冷却期内不会重复出现。人工可选择继续淘汰、恢复为梗或恢复为口癖；程序不自动恢复。

默认参数见 `ops/meme_lifecycle.example.json`。
