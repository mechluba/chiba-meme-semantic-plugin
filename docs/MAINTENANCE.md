# 梗库长期维护方案

目标不是无限堆梗，而是持续得到“当前有人用、语义明确、放进聊天不会尬”的小而活的梗库。候选发现可以自动化，进入线上必须经过人工审核和版本化发布。

## 一条完整流水线

```text
B 站高互动内容
→ 顺藤摸瓜扩展视频与圈层
→ 弹幕/评论语义聚类
→ 与现有梗库向量去重
→ 模型生成候选梗卡
→ 人工审核
→ 离线回放
→ 测试环境真实 Planner/Reply
→ 同一 commit 晋级生产
→ 线上效果反哺更新与退场
```

### 1. 每日发现

以 B 站近期高互动视频为主入口，不再以百科式老梗清单作为主要数据源。

- 从已验证圈层和种子视频出发，沿相关视频、二创作者、合集、热评引用和同一弹幕表达扩展。
- 优先看近期新增弹幕/评论速度、互动密度、跨视频重复、跨作者传播和回复链深度，而不是只看累计播放量。
- 只采集用户真实表达及其上下文。视频标题、UP 主口播或站内 UI 文案不能单独构成梗。
- 每条证据记录 BV 号、评论/弹幕 ID、观察时间、圈层和上下文，不只保存一句字面文本。

建议每天生成候选池，但不自动进入线上 Release。

### 2. 语义发现与去重

不使用正则或固定关键词判定。

- 对评论/弹幕连同前后文做 Embedding。
- 在单视频内聚类，找高密度重复语义；再跨视频和跨作者聚类，判断是否真的传播。
- 将新簇与现有路线原型做向量比较：同义表达合并到旧卡的新证据或新 realization；交流意图不同才新建卡。
- 用模型从证据簇提炼 `semantic_core`、适用场景、交流意图、允许表达、正例、反例和硬性禁用语境。
- 模型只能生成候选，不能自动标记为已审核。

### 3. 时效性

每张卡补充并持续更新以下事实：

- `first_observed_at`
- `last_observed_at`
- `recent_evidence_count`
- `unique_video_count`
- `unique_creator_count`
- `interaction_velocity`
- `online_use_count`
- `natural_use_rate`
- `forced_use_rate`

状态分为：

- `current_observed`：近期仍在多个独立内容中自然出现。
- `evergreen`：不是近期爆发，但长期可理解且线上使用稳定自然。
- `fading`：传播和自然使用持续下降，只保留理解能力，不再主动使用。
- `retired`：不再进入召回索引，证据和历史卡仍归档可追溯。

退场不能只按年龄一刀切。老但常用的梗可以是 `evergreen`；新但只出现于单个视频的表达不能因为“新”就上线。

### 4. 人工审核

每周集中审核一次候选和状态变化：

- `USE`：共同语境明确，表达短、自然，正反例充分。
- `UNDERSTAND_ONLY`：能帮助理解用户，但主动复读容易冒犯、尴尬或显得装懂。
- `SKIP/REJECT`：纯视频网站操作语、证据不足、只是一句普通话、语义含混或风险高。

审核页应展示原始证据上下文、来源时间、跨视频传播、与旧卡相似度和模型为什么建议该动作。审核结论保留操作者、时间和备注。

### 5. 发布门禁

每次 Release 都执行：

1. 锁定审核通过的 library。
2. 为每条 usage route 生成多原型向量。
3. 校验卡数、route 数、向量数和 SHA256。
4. 离线测试召回 Top-3、误召回和硬禁用场景。
5. 真实 Planner → Replyer 至少覆盖：自然使用、Planner 跳过后语义裁判使用、严肃场景跳过、日常无关场景跳过、`UNDERSTAND_ONLY` 不复读。
6. 测试环境观察后，用同一插件 commit、Release 和模型任务配置晋级生产。

任何卡片内容变化都新建 Release，不原地修改已上线目录。

### 6. 线上反馈与退场

每天聚合结构化观察事件，按卡和 route 统计：

- 被召回但跳过
- 被授权且真正使用
- 使用自然
- 使用生硬
- 严肃语境误触发
- 内部提示泄漏
- `UNDERSTAND_ONLY` 质量门拦截和重生成

建议每周做一次状态判定：

- 严肃误触发或内部泄漏：立即停止主动使用，进入 `UNDERSTAND_ONLY` 或回滚 Release。
- 连续两周高召回、低真实使用：重写 route/原型，不要靠降低全局阈值硬推。
- 连续四周传播下降且线上自然使用不足：转 `fading`。
- 连续八周无新证据且无稳定自然使用：从新 Release 的索引移除并标记 `retired`。

这些周期是初始运营阈值，累计两到四周真实数据后再校准。

## 固定节奏

- 每日：采集、聚类、生成候选和新鲜度更新。
- 每周：人工审核、退场评审、离线回放、发布候选 Release。
- 每两周：测试环境真实链路验收，通过后晋级生产。
- 每月：按圈层看覆盖缺口、误触发和自然使用率，决定下一轮种子。

梗库规模不是核心指标。更重要的指标是当前有效卡占比、真实自然使用率、误触发率，以及一个梗从出现到进入候选池的时间。
